## 风格 prompt 段（可直接复制进 seedream / gpt-image-2）

> 中国水墨毛笔画风格，飞白墨线勾边、淡彩渲染、宣纸质感；天宫云海祥云缭绕、淡墨鎏金楼阁楼台，暖旧米金色调，庄重怀旧、不卡通不低幼。角色一律保留《造梦西游》标志性布偶缝合脸（X 形缝线嘴、脸上缝疤、一只大眼、红色脸蛋）与 Q 版三头身比例，造型/发型/头饰/武器/配色严格忠实原版、不天马行空。画面里绝对不要出现任何文字。

风格锚定手法（正式件必用其一，保证与锚自洽）：
1. **image-to-image**：把锚图作为 ref 之一喂进去（seedream `--image 锚图 --image 角色参照`），最稳。
2. 无法 i2i 时用**同一段风格 prompt** + 同色板词，且喂原版角色件当角色参照。

## 禁忌清单（任何生图都不许出现）

- ❌ 3D 渲染感 / C4D / Octane 质感（要手绘水墨平面）
- ❌ 日系厚涂 / 赛璐璐动画感 / 美式卡通
- ❌ 写实照片感 / 影楼光
- ❌ 改角色形象「天马行空」：发型/服装/武器/脸部必须对参照，比例锁 Q 版三头身
- ❌ 低幼卡通、糖果色、Q 弹塑料玩具感
- ❌ 画面里任何文字（标题字单独渲染，不在场景图里生成）
- ❌ 冷调偏色跑出宣纸暖旧锚（如纯青玉冷绿主调——地面 B 候选即因此偏离锚被降级）
- ❌ **角色参照用灰度/未选中滤镜态图**（可复现坑）：`select_role_idle.png` 五格里除悟空外是原版"未选中滤镜灰"态，拿它当角色 ref 会把八戒/沙僧上色拖成灰白掉饱和（keyart C 首版即栽在这——八戒沙僧被洗色，需返修）。**角色配色 ref 必须用全彩动作帧** `role{2,3,4}_0.png`（唐僧/八戒/沙僧的真彩本体），灰度图只可用于读造型/轮廓，绝不用于定色。

## 补色裁量授权（用户 2026-07-08 拍板，长期有效）

若某角色/素材的**真源配色本来就淡或缺色**，授权在生图提示词里为其补全最合适的对应颜色——**合理演绎优先于死守淡色**。

边界（勿误用）：此条只对「真源本就淡/缺色」生效。**真源有饱和配色时仍按真彩帧走，不许拿此条当洗色/魔改的借口**——八戒沙僧真源不淡（role3/role4 全彩帧饱和），本次按真彩帧重上色，不适用此条。典型适用场景：第五格黑影（原版就是纯剪影，可裁量赋予神秘色调）、可能出现的灰调/缺色场景件。

## 汉字/标题特例

生图模型写汉字（尤其「续」等复杂字）高概率崩字缺笔。**标题与 UI 书法字一律走字体渲染 + 飞白后处理**，脚本 `tools/render-title-calligraphy.py`（系统 Xingkai 行楷 / Baoli 报隶 + 横向飞白干笔 + 墨晕）。零错字硬判据，不接受生图崩字件。
