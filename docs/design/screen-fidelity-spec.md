# 逐屏保真规格（主会话亲自判读，2026-07-08 01:00）

参照真源：`docs/reference/user-flow-refs/`（用户 2026-07-08 提供的 14 张全流程对照图）+ Ruffle 活原版（docs/research/ruffle-reference.md）+ vendor SWF 对象树。
方法铁律（feedback-ui-fidelity-pixel-diff）：布局坐标抄 SWF 对象树 PlaceObject、位图用原件零手绘、每屏交付叠加 overlay 对比、主会话逐屏终审。样式判断以本文档 + 参照图为准，worker 不得自行发挥。

## 屏幕流结构（最大缺口是层级，不是样式）

原版流：主菜单 → 存档 → 选人 →（模式选择）→ **世界地图 hub** → 关卡战斗 → 回地图。
我们现状：主菜单 → 选档 → 选人 → 直接战斗（关卡间传送门串行）。
**判定：新增 WorldMapScene 作为 hub**；保存/炼丹炉/学习技能/任务入口原生长在地图底部按钮排，炼丹炉从"战斗中对话"迁移为"地图上老君入口"（战斗内对话保留闲聊）。模式选择（单人/双人）暂不做（无双人系统，不造假），选人确认直接进地图。

## S1 世界地图（worldmap-original.png）｜优先级 1，结构性

- 全屏浮空岛手绘地图（金顶天宫居上、各关卡岛屿散布、云海）；左右上角"补偿礼包"宝箱（营运件，可暂缺）。
- 底部横排圆形红金按钮：保存游戏/商城/炼丹炉/学习技能/活动/任务/返回，图标+竖排小字。
- 关卡入口 = 地图上的岛屿/建筑热点，当前进度可点、未解锁置灰；点击进关。
- 素材：vendor OtherMat 系符号（升级调研提过带整套 SelectPlace）；FFDec 搜 SelectPlace/map/place 符号族，地图大图+按钮件按对象树取。挖不到的营运件（宝箱/活动）记缺不造。
- 接线：选人确认→本场景；四关入口映射 CAMPAIGN；保存=现 SaveSystem；炼丹炉=FurnacePanel（复用，材料从存档背包）；学习技能=占位板（S5 落地前置灰）；返回=主菜单。
- 判据：流程截图三连（选人→地图→点岛进战斗→通关回地图）+ 与参照图 overlay；401+ 测试绿。

## S2 选人（selectrole-original-{idle,1p,2p}.png vs selectrole-ours.png）｜优先级 2

- 原版：**五格全屏直通到底**，无外框无大标题无底部按钮条；格间墨迹分隔。
- 未选态：全员灰度立绘，底部书法体名字（孙悟空/唐僧/猪八戒/沙僧/？？？），第三格下方"请输入名字"小字。
- 选中态：该格背景变红 + 立绘上彩 + 顶部"1P"墨迹角标。确认=再次点击/回车（跟 Ruffle 实测行为对齐）。
- 我们的差距：格子缩小加了金边框、顶部"选择角色"大标题、底部返回/确定按钮、悟空格里叠了小 sprite——全删，照原版全屏格式重做。
- 素材：vendor SelectRole 符号族（meta-shell 已挖到五格墨迹立绘）；灰度=原版自带灰度件优先，没有才 tint。
- 判据：三态（未选/选中/确认瞬间）与参照三图逐张 overlay；仅悟空可选其余灰锁（现状功能不变）。

## S3 存档（saveslots-original.png vs saveslots-ours.png）｜优先级 2（与 S2 同棒）

- 原版（Online 版式，用户指定）："存档记录"标题居中、深灰圆角双列卡片、左侧橙色大编号、卡内两行=角色名（多角色空格连写）+ 时间戳、右上红 X 关闭、无金边框。
- 我们的差距：金框卡片+加号+"空存档位"文案版式自创。重做为参照版式；空档显示"空存档位"但样式从深灰卡片。
- 判据：与参照 overlay（结构层）；6 槽增删读功能不变。

## S4 个人资料/背包（profile-backpack-original.png）｜优先级 3

- 墨迹大窗"个人资料"：左栏=昵称/战斗力条、等级翼徽、立绘+左右装备槽（武器/头/衣/饰件）、十项属性表（HP/MP/攻击/防御/幸运/魔抗/暴击/闪避/回血/回蓝，双列金框条）、底部 EXP 长条；右栏=装备/道具/时装/经书 四页签 + 5×5 图标格 + 灵魂计数 + 出售白装 + 页码 1/2。
- 现有 BackpackWindow 结构近似但版式差远。素材：vendor backpack1.swf（export.strength.* 已提取部分）+ BackPack 符号族，对象树取坐标。
- 无对应系统的页签（时装/经书）做置灰页签不造内容；战斗力=atk/def/hp 简单合成公式，report 注明自定。
- 判据：与参照 overlay；穿脱/出售功能回归绿。

## S5 技能树/学习技能（skilltree-original.png）｜优先级 4

- 顶栏：角色名徽 + "每个角色只能学习5个技能…孟婆药剂"说明 + 返回。
- 左栏：心法一/心法二卡（墨字图腾 + 当前等级 + 升级所需灵魂）。
- 右栏：技能表格（技能名称/技能图标/技能说明/按键设置四列，行分隔线）；底部 主动技能/被动技能/BOSS技能 页签 + 灵魂计数。
- 逻辑直接移植 kagami HERO_SKILL_TREES + SkillBinding（悟空斩系/火系双心法现成），**顺带解决"9 技选 5 上坞"**：按键设置列=绑定 YUIOL。
- 素材：RoleSkillInterfacev3550.swf（已解，技能图标 66px 亮版就在这）对象树。
- 判据：与参照 overlay；绑定后坞上技能真实生效；灵魂货币没有→用现有材料/占位并 report 注明。
