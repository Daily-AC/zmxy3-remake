# 造梦西游3 玩法与产品解剖

> 目的：为重制 + agent NPC 项目提供一份"吃透原游戏设计意图"的权威底稿，用来做 MVP 功能取舍。
>
> 双信源交叉：**一手**＝kagami 逆向文档（从 ~20 万行 AS3 蒸馏的机制事实，回答"是什么"）；**二手**＝4399 社区/知乎/百科/攻略（玩家与产品视角，回答"为什么火 / 为什么这么设计"）。凡一手二手冲突处，本文明确标注并给判断，不和稀泥。
>
> 一个前提纠正：kagami 的 `mechanics-index.md` 里"复现状态"那一列是 **kagami 自己项目的进度**，不是我们的。我们项目的真实进度在 `progress.md`——目前是悟空战斗切片 + 掉落/背包/装备最小闭环 + agent NPC 对话层 + 炼器最小原型 + 打包 spike。下文凡说"我们已有/缺"，都以 `progress.md` 为准。

## 1. 一句话定位 + 品类坐标

**造梦西游3（大闹天庭篇）是一款横版 2D 动作 RPG，把"格斗游戏的连击手感"和"MMO 的养成刷装"缝在一起，跑在 Flash 页游的躯壳里，卖给 2011 年前后的中国青少年。** 2011-12-29 上线于 4399，被公认为造梦系列的巅峰。

品类坐标（三个锚点决定了它所有设计取舍）：

- **动作横版清版**（像素级碰撞、连段、击退、二段跳）——决定了"打得爽不爽"是第一体验。
- **数值养成 RPG**（等级/装备/宠物/法宝/战力）——决定了"为什么要一直玩"。
- **4399 免费页游 + 内购变现**（VIP 5 档 10~500 元、点券、每日次数券）——决定了系统为什么要设计得这么"深"和"卡脖子"：深度不是为了好玩，一半是为了留存和付费。

对标物：横版战斗手感对标《地下城与勇士》的页游青少版；养成刷装对标 MMO；宠物捕捉/进化对标宝可梦式收集。它的独特卖点不是任何单一维度做到极致，而是**在一个免费页游里同时给了动作爽感 + 养成深度 + 本地双人 + 熟悉的西游 IP**——这个组合在 2011 年的 4399 上几乎没有对手。

**为什么是"3"火而不是别的代**（二手共识）：① 大闹天庭是西游记里知名度最高、BOSS 最密集（天庭众神都能当 BOSS）的桥段，IP 势能最大；② 到了 3 代师徒四人才真正集齐进一个游戏，角色阵容完整；③ 3 代首次引入剧情任务、宠物战斗、线上 PK、同屏聊天，玩法密度跃升。IP + 角色完整度 + 玩法密度三者叠加，才有了"巅峰"。

## 2. 玩家核心循环

### 单局怎么玩（一次关卡）

一手（`levels-index.md` / `runtime-index.md`）证实的单局骨架：

**菜单选人（单人只设 P1，双人先 P1 后 P2）→ 大地图选关 → 进入关卡 → 纵向爬升 / 横版推进，边走边打周期刷出的小怪 → 越过高度阈值触发 BOSS 区（镜头锁定）→ 单体 BOSS 战 → BOSS 死后出现传送门 → 站门按"上"结算 → `levelClear()` 更新大关进度并存档 → 回大地图选下一关。**

关键手感参数（都来自一手，是"造梦味"的物理地基）：

- 移动慢而稳：走 6 / 跑 10（500ms 内双击同向进入跑）、跳跃 `jumpPower=-20` 最多二段、`下+跳`只在标记平台下穿。
- 刷怪是"陪伴式"而非"压力式"：1-1 里计时器归零后单人刷 2 只、双人刷 4 只，位置紧贴玩家（`x±150`），间隔约 6 帧单位。**目的是让"移动中永远有怪可打"，不是堆怪墙**——纵向爬升本身才是推进变量。
- 打击感由一条链构成（`combat-rules-index.md`）：每次攻击有唯一 `attackId` 做同帧去重 → 读取动作的击退向量 `attackBackSpeed`（命中后 `speed.x*2`，0.4 秒衰减到 20%）→ 物理 `(atk-def)/atk` 比例伤害（上限 1.1 倍、下限保底 1）→ 受击方进入受击反馈 → **受击条累积满 19 触发约 3 秒无敌**，防止被连成沙包。

### 每天怎么玩（日常循环）

一手文档只覆盖到"通一关"的主线闭环，**没有覆盖日常刷什么**——这是逆向的盲区，靠二手补上，且这一块恰恰是留存的核心：

- **玲珑宝塔**：24 层连续闯关，每 6 层一个 BOSS（土行孙 / 雷震子 / 哪吒 / 托塔天王），血蓝不回满、难度按绿蓝紫橙红递增，哪吒和托塔天王掉"目前属性最好的饰品制作书及材料"。这是**主要的可重复刷宝场所**。
- **竞技场 PK**：20 级开放、30 级完成"解救地藏"任务后解锁，是玩家攀比和炫耀 build 的舞台（沙僧毒杀流、暴击流等流派文化就长在这里）。
- **每日次数制内容**：签到、祈福、挑战副本、远航、秘境探索——这些的"每日次数"正是 VIP 特权兜售的东西（VIP 逐级增加每日祈福/副本/远航/秘境次数）。
- **药园 / 宠物养成**：后期药园升到 9 级很常见，长期供养宠物。

### 爽点在哪 / 什么让人第二天还想登录

- **即时爽点**：连段打空一屏怪的清版快感 + 掉落物"叮"地吸进背包的正反馈（掉落有红/白光环自动吸附）。
- **中期爽点**：炼丹炉里把攒够的材料 + 装备书合成出一件更强装备，属性肉眼可见地涨——"变强"的确认时刻。
- **留存钩子**：① 关卡难度墙——下一关打不过，逼你回去刷装备；② 宠物/装备的 RNG（技能随机学习、资质随机、掉率保底）制造"再来一次也许就出货"的心理；③ 竞技场排名和 build 攀比——社交压力；④ 每日次数券——不上线就亏了的损失厌恶。

## 3. 系统全清单（是什么 + 为什么存在）

### 3.1 战斗系统 — 地基

- **是什么**：连击（各角色 `hit1..hitN` 分段循环，如悟空五段、八戒三段）、技能槽、无双/特殊键（Space，独立不占槽）、法宝键（H，独立）、暴击/闪避/吸血（数值层修饰）、击退、受击保护窗、物理/魔法两套伤害公式。
- **对玩家**：动作手感是第一留存——打得不爽，后面养成再深也留不住人。**连击去重 + 击退 + 受击保护这三件是"骨"**（保证连续输出有正反馈但不会被秒），暴击/闪避/吸血/韧性是"数值皮"（一手文档反复把它们标"后置"，连原作者都当作修饰）。
- **对产品**：战斗是消耗养成数值的出口——没有一个能持续变难的战斗场景，养成就空转。

### 3.2 五角色差异 — 不是换皮

一手（`roles-index.md`）证实是**真实职能分化**，不是换色：

| 角色 | 定位 | 招牌机制 |
|---|---|---|
| 悟空 Role1 | 标准近战 DPS | 五段连击 + 吸血暴击被动 `sx` |
| 唐僧 Role2 | 唯一辅助/治疗 | 8 个主动里 5 个不直接造成伤害（群疗、拉拽控制、护盾、分身传送）|
| 八戒 Role3 | 坦克 | 三段循环 + 吸血防御被动 `rj` + 三档护盾（免击退、减伤）|
| 沙僧 Role4 | 毒系/控制 | 铲/弓双形态、`mds` 毒层超 2 触发毒爆（竞技场毒杀流之源）|
| 白龙 Role5 | 形态切换（同人扩展）| 枪/剑双形态，速度/连段/系数全不同，复杂度最高 |

- **对玩家**：角色差异 = 重复可玩性 + 流派文化（"沙僧娃娃+木魔单挑""暴击流插 3 颗雷灵珠"）。
- **对产品**：多角色 = 多套养成线 = 多倍时长；也给了"换个角色重新肝"的理由。
- **双人**：本质是两套独立键位（P1 字母区 + P2 方向键/小键盘）驱动同一状态机，**无跨玩家联动逻辑**，纯并行输入 + 共享怪物数组；但数值按双人做过适配（刷怪翻倍、BOSS 触发条件是"任一玩家到达"）。本地双人是**默认核心形态之一，不是后加模式**。

### 3.3 养成线 — 让人一直玩的引擎

- **等级/经验**（`progression-index.md`）：上限 90，五角色共用经验曲线（19 级后每级 `5000+5000*(L-19)`，陡峭），各角色独立属性成长公式。**带宠物出战时玩家和宠物各分 60% 击杀经验**——这条把宠物和主线牢牢绑在一起。
- **装备**：槽位含防具/武器/饰品/法宝/时装/头衔。强化是每件绑定的一次性属性包（品质越高增量越大，普通 +4 防御 vs 优秀 +40 血/+20 蓝/+4 防御）；宝石 3 级、跨级跳跃剧烈（生命石 1 级 +20 → 2 级 +145）；**合成走"3 材料 → 1 成品"金字塔且多层嵌套**（BOSS 装备 → 法宝雏形 → 进阶法宝）。
- **炼丹炉（合成中枢）**：玩家在大地图进炼丹炉，放入"装备制作书 + 材料"合成装备/法宝。这是养成飞轮的**中枢节点**——把"打关卡掉的碎料"变成"看得见的战力"。⚠️ 一手状态：合成 M-039 在 kagami 侧也是"未扒/未复现"，我们侧同样空白。
- **战力**：⚠️ **一手二手冲突**——kagami 在代码里**没找到账号级综合战力评分**（宠物内部有局部 `warpower`，非全账号聚合）；但玩家口中普遍在说"战力"（"玲珑玉对战力增幅很大"）。判断：原版大概率没有醒目的单一战力数字，而是靠"每条养成线互相设软性前置门槛"逼玩家多头并进；玩家说的"战力"是各属性的口头统称。重制时"补不补一个聚合战力数字"是产品取舍，不是技术必然。

### 3.4 宠物系统 — 招牌 + 变现主力

一手（`pets-index.md`，83KB，是所有文档里最重的）证实这是**与角色等级同权重的第二成长轴，而非收藏支线**：

- 12 条独立进化链（monkey/horse/dragon/phoenix/turtle/ufo…）、每形态**替换**而非叠加技能；上限 90；四类资质线性驱动成长；悟性/技巧/战力三维（各封顶 8）靠**洗练丹加权随机重投**（本质数值抽卡）；技能在特定升级窗口 40% 概率随机学习、可用洗练丹重掷；捕捉靠宣花葫芦（命中率 0.4~0.7，命中固定扣 5000 灵魂）。
- **为什么这么大**：主线等级/装备是收敛资源，练满即到顶；宠物用"12 种 × 4 形态 × 资质重投 × 技能 RNG × 捕捉概率"制造组合爆炸，专填主线外的时间。更狠的是**宠物是真实战力乘子**——四个被动 buff（`smjc/mfjc/gjjc/fyjc`）直接加主人 HP/MP/攻击/防御上限，加上分走 60% 经验——不养宠物，成长速度打六折。这是结构性绑定。
- **对产品**：宠物本体商城直购 + 续命/洗练/进化走消耗品经济 + 捕捉又和法宝共享"灵魂"货币池——三条付费路径并行。**这是被当作变现主力设计的**。二手也印证宠物战斗是 3 代的招牌新玩法。

### 3.5 法宝系统 — 寄生在装备槽的第三条线 + 资源枢纽

- **是什么**（`magic-weapons-index.md`）：结构上是装备五数组之一，穿脱同装备；但成长曲线（灵魂**二次方**消耗 `level²*1000` + 高阶专属稀有材料）和普通装备完全不通用，操作走独立键（H）。20 个法宝里的"宣花葫芦"就是宠物捕捉的唯一战斗内实现。
- **定位判断**：法宝不是装备附属也不是宠物延伸，而是**寄生在装备槽里的独立第三养成线**，同时是连接"装备经济"和"宠物获取经济"的接口（共享灵魂货币）。

### 3.6 关卡 PVE 推进与 BOSS — 养成的用武之地

- **是什么**：大关 × 小关两级结构（1-1、1-2…）；关卡分纵向爬升型（到点触发 BOSS）和横版停点型（`StopPoint` 把地图切成"清场才能推进"的战斗节拍）；BOSS 触发靠高度阈值或清场。
- ⚠️ **BOSS 机制的一手盲区**：kagami 文档对 BOSS 着墨有限——目前证据只显示 BOSS 是"数值和 CD 更硬的怪 + 专属血条/受击蓄积条 + 受击满后短暂无敌可能反击"，**没有逆向到弹幕或多阶段脚本**。而二手（社区攻略、"各 BOSS 技能详解"）强烈暗示 BOSS 战有丰富专属机制和技能。判断：BOSS 的独立机制是真实存在但一手尚未扒透的深水区，真要做需逐个逆向具体 BOSS 类。**BOSS 是关卡爽点和难度的主要来源，但也是复刻成本最高、当前知识最薄的部分**。

### 3.7 PK/竞技场/社交 — 留存引擎

- **是什么**：竞技场（20/30 级解锁）、线上 PK、同屏聊天。一手只看到 `Stage 0-1` 里的 `pkDoor` 跳转接口，机制本体未深扒（依赖多人/账号系统）。
- **对产品**：这是**长期留存的社交引擎**——排名、build 攀比、流派文化都长在这里。但它依赖联网，成本高、离单机核心远。

### 3.8 经济系统 — 飞轮的燃料泵

- **掉落**（`drops-index.md`）：装备/道具（BOSS 掉率 ×1.5，时装再加成）、药品、灵气自动吸附三通道；动态稀缺软保底 `pow(avgCount/(currentCount+1), 2.4)`；掉率梯度实证——早期材料 0.12~0.18、后期合成碎片降到 0.02~0.05，**高价值材料精确绑定到具体 BOSS + 具体关卡**，逼你反复刷固定路线。
- **货币/付费**：点券（VIP 1~5 档 = 10/50/100/200/500 元）、灵魂（法宝升级 + 宠物捕捉共用）、每日次数券。付费面三层并存：材料稀缺型（逼刷指定关）、概率型（买时装买好运/买洗练重投）、直购型（商城直卖成品绕过合成）。

## 4. 系统咬合飞轮

```
                     ┌──────────────────────────────────────────┐
                     │                                          ▼
   等级/经验 ──→ 打关卡 PVE ──→ 掉落(材料/装备书/碎片) ──→ 炼丹炉合成 ──→ 装备/法宝变强
      ▲            │  ▲                                              │
      │            │  │                                             ▼
      │            │  └──────────── 战力涨 ←── 强化/宝石/灵魂 ←───────┘
      │            │                   │
      │            ▼                   ▼
      │      更难的关卡/玲珑宝塔    竞技场 PK 赢 ──→ 攀比/排名/流派文化(社交留存)
      │            │
      └── 宠物出战分 60% 经验 + 四被动加主人属性(第二成长轴, 变现主力)
```

**留存引擎判断**：短期留存靠**"关卡难度墙 ↔ 养成"这个主飞轮**（打不过 → 回去变强 → 推进 → 打不过下一关）；长期留存靠**竞技场社交攀比 + 宠物/装备 RNG 的抽卡心理 + 每日次数券的损失厌恶**。变现主要挂在宠物、时装、灵魂货币和 VIP 次数上。

飞轮能转的**充要条件**是：① 战斗手感够爽（否则第一步就断）；② 有一串难度递增的关卡/BOSS（否则养成没有"用武之地"和"逼迫点"）；③ 有一个把掉落变成战力的合成中枢（炼丹炉）。**这三者任缺其一，飞轮空转。**

## 5. 对我们 MVP 的意义（最重要一节）

### 骨 vs 肉

**骨（不做就不成其为造梦西游 3）：**

1. **横版动作战斗手感**——连段去重 + 击退 + 受击保护 + 暴击。地基。
2. **至少悟空一角**——五段连击 + 技能槽 + 无双键。身份认同。
3. **关卡 PVE 推进**——纵向爬升/横版停点 + 周期刷怪 + BOSS 区 + 传送门通关，且是**一串难度递增的关卡**，不是单张图。舞台。
4. **掉落 → 背包 → 装备 → 炼丹炉合成/强化**——把"打"变成"变强"的闭环。动机。
5. **等级/经验成长**——最基本的数值反馈。

**肉（可后置，但有优先级）：**

- **第一批肉**：宠物系统（庞大且是招牌"宠物战斗"，情怀权重高，但 MVP 可无；上则整个第二成长轴一起来）。
- **第二批肉**：法宝（H 键独立线）、五角色/双人（悟空先行）、心法树深度、宝石/五行/洗练。
- **第三批肉（依赖联网/账号）**：竞技场 PK、同屏聊天、玲珑宝塔/每日副本/远航等日常刷本、VIP/付费。这些是留存/变现引擎，但离单机核心最远，且我们是私有非商业项目，付费系统基本不需要复刻。

### 我们现在处在这张全景里的什么位置

对照 `progress.md`，我们已有：**战斗手感切片（悟空 + Monster30 互伤、连击、击退、受击保护）✅ | 掉落→背包→装备最小闭环 ✅ | 等级/经验最小闭环 ✅ | 关卡第 1 关切片（纵向爬升 + 刷怪 + BOSS + 传送门通关）✅ | agent NPC 对话层 ✅ | 炼器 NPC 最小原型 ✅ | 打包链路 ✅**。

也就是说，**五根"骨"里我们已经立起了 4 根半**——独缺**炼丹炉合成中枢**这一根，以及关卡目前只有"一张图"而非"一串难度递增的关卡"。

### 最大的关键缺口（按补齐优先级）

1. **炼丹炉合成系统（M-039，一手都还没扒透）**——这是养成飞轮的中枢。没有它，掉落的材料和装备书无处可用，"打关卡 → 变强"的闭环断在中间，装备强了也只是孤立数值。**这是骨里唯一的空白，第一优先。**
2. **一串难度递增的关卡 + BOSS**——现在只有 1 关。造梦的核心循环是"推进→打不过→回刷→再推进"，没有第 2、3 关和难度墙，养成没有逼迫点，飞轮空转。BOSS 专属机制是一手盲区，需逐个逆向（成本最高）。
3.（次要）宠物系统——招牌情怀，但属第一批肉，可在骨立稳后再上。

### agent 驱动 NPC 增量嵌在哪最有戏

**第一落点：炼器 NPC 嵌"炼丹炉 → 装备线"（强烈推荐）。**

- 理由：炼丹炉本就是养成飞轮的中枢节点，玩家有现成心智模型（"进炉子放书 + 材料合成"）。原版这里最枯燥的体验是"查配方表凑材料"。把 agent 炼器 NPC（我们已有最小原型）嵌在炼丹炉，用自然语言现场生成**独一无二、沙箱校验的装备/法宝**，等于把"配方查表"升级成"跟太上老君对话炼宝"。增量嵌在玩家已有行为路径上，且正好补我们最大的骨缺口（合成中枢）——**一举两得：既立起缺的骨，又让 agent 增量落在飞轮中枢**。
- 我们已有装备闭环 + 炼器原型 + 沙箱 DSL，落地路径最短。

**第二落点：对话 NPC 嵌"任务 → 关卡/剧情线"。**

- 我们的对话层 NPC 已能引用游戏事件、动态发任务。原版剧情是全屏漫画分镜（静态），动态发任务能补它的短板。但任务系统本身我们还没做，依赖关卡推进先铺开，优先级排在炼器之后。

### 明确结论：造梦手感最小骨架

**= 横版动作战斗手感（悟空连击/无双/击退/受击保护）+ 一串难度递增的关卡 PVE（刷怪/BOSS/通关）+ 掉落→背包→装备→炼丹炉合成强化 + 等级成长。** 这四块转起来，就已经"是造梦西游 3"了；宠物/法宝/竞技场是让它"更像、更耐玩"的肉，可增量叠加。

**我们最大的缺口 = 炼丹炉合成中枢（骨里唯一空白）+ 第 2 关起的难度递增关卡链（现在只有 1 关，飞轮没有逼迫点）。** 这两者补上，养成飞轮才真正转起来；而 agent 炼器 NPC 恰好应该嵌在"炼丹炉合成"这个缺口上，一箭双雕。

## 6. 双视角提炼

### 玩家为什么爱玩（爽点）

1. **清版连击的即时手感**——一套连段打空一屏怪，击退和打击反馈给得干脆。
2. **肉眼可见的变强**——炼丹炉合成 / 强化装备 / 宠物进化，每一步属性都看得见地涨。
3. **收集与抽卡心理**——12 种宠物、多形态、资质/技能 RNG、捕捉概率，"再来一次也许出货"。
4. **流派 build 的自我表达**——沙僧毒杀、暴击流插雷灵珠，竞技场里炫耀自己的搭配。
5. **熟悉 IP + 师徒四人 + 本地双人**——西游情怀 + 和朋友同屏一起打的社交记忆。

### 产品为什么这么设计（留存/商业逻辑）

1. **难度墙 ↔ 养成的主飞轮**——用"下一关打不过"逼玩家回刷，制造可控的时长消耗。
2. **多线互相设软门槛**（等级/装备/宠物/法宝互卡）——不做单一战力数字，逼玩家多头并进，防止只肝一条线就满足退坑。
3. **RNG 无处不在**（掉率梯度、资质重投、技能随机、捕捉概率）——用不确定性制造重复动机和付费冲动（花钱买好运）。
4. **每日次数券 + VIP 分级**——用损失厌恶（不上线就亏）和特权阶梯（VIP 1~5，10~500 元）驱动日活和 ARPU。
5. **宠物/时装/灵魂货币作变现主力**——把付费点挂在"可选但强力"的养成侧，而非卡死主线，符合免费页游"体验免费、变强付费"的商业模型。
