# 原版数值三路交叉验证报告

**任务**：验证我们的真源 SWF（`vendor/…造梦西游魔改版/` 内含"再续天庭 0.72"）的关键数值，是否被魔改，对照"原汁原味造梦西游3"。
**日期**：2026-07-09
**只读范围**：本报告 + `vendor/zmxy-datasource/`（clone）+ `tmp/re-level1/`（已导出 AS3）。未改 game/src，未 commit。

## 结论先行（TL;DR）

**用户点名怀疑的三处——乌鸦 hp=1、经验给得少（exp=4 + 高等级清零）、掉落低概率——经三路交叉验证，全部是原版忠实数值，不是魔改。**

- **乌鸦 hp=1**：第三方权威血量表独立列出"乌鸦：1 HP"，与我们 SWF `setHp(1)` 逐字一致。乌鸦是 1 血飞行小怪，"打好几棍"的记忆来自它**会飞、你打空**以及它在巨灵神 BOSS 战里反复作为骚扰 adds 出现，不是血厚。
- **exp=4 + 8/10 级以上清零**：网络攻略原文"乌鸦（八级以上无经验）给 4 经验和 2 灵魂"，与 SWF（exp=4、gxp=1→2 灵魂、等级门）一致。这是原版**防低级图刷经验**的机制，不是魔改。
- **掉落低概率**：小怪 15% 掉率、BOSS 100% 掉新手装，是原版设计；与团队已确认的 fallEquip 单掷模型自洽。

**我没有找到任何一处早期/九重天核心战斗数值被魔改的证据**——三路（SWF / ZMXY 数据源 / 网络攻略）在这些数上都对得上。"魔改版"目录名指向的很可能是别的东西（解锁全角色/宠物、作弊菜单、或后期内容/掉率），**不是**用户担心的这几个数。诚实的边界：要坐实"哪里被改了"，需要一份**干净的再续天庭 0.72 原版 SWF** 做逐字节 diff，我手上没有这份基线（见"挖不到的"）。

## 一、数据源可靠性与口径（先说清，否则对照表会误读）

1. **"九重天"是两个游戏的混淆点**。九重天是**原版《造梦西游3·大闹天庭篇》的第一关**。我们的 SWF 和 ZMXY 数据源都是**《再续天庭》**——这是 4399 后续的大版本，地图是"天宫道/凌霄殿/南天门…"（见 `gameConstants.json` stageNames），**没有叫"九重天"的关**。用户记忆里的"九重天乌鸦"属于原版大闹天庭篇；但乌鸦这只怪在两代里是同一个 1 血飞行小怪，数值可直接对照。

2. **怪物 ID 编号在两边不通用**。SWF 的 `MonsterNN` 类编号 ≠ ZMXY `monsters.json` 的 `id`。证据：SWF `Monster30`=乌鸦（1 血飞行），而 ZMXY `monsters.json` id30="海巫 hp29125"——明显是**不同版本拼进来的错位条目**。**只能按怪物中文名对齐，不能按编号对齐。**

3. **但 ZMXY 的关卡波次（levels.json）和 SWF 对得上**。SWF `StageListener13`（第 1 大关第 3 小关）注册 `["Monster8","Monster7","Monster5","Monster30"]`；ZMXY `sl13` 波次 enemyType 用的正是 8/7/5/30/3。**关卡结构可信，逐怪 monsters.json 数值只在名字能对上时可信。**

4. **ZMXY 数据源本身也是二手重制**（Phaser3+TS 的 HTML5 fan remake，README 自称"造梦西游3 再续天庭"，git 仅 1 个 commit"添加加载界面"）。它是佐证，不是权威原版。

## 三、逐项判定与置信度

| 用户怀疑点 | 判定 | 置信度 | 依据 |
|---|---|---|---|
| 乌鸦 hp 被改成 1（原版应血厚） | **原版就是 1 血**，非魔改 | **高** | 网络血量表逐字"乌鸦 1HP" + SWF `setHp(1)`；乌鸦是飞行骚扰怪，"好几棍"=打空/巨灵神战 adds |
| 经验被砍（乌鸦 exp=4 + 高级清零） | **原版设计**，非魔改 | **高** | 攻略原文"8 级以上无经验，给 4 经验 2 灵魂" = SWF exp4/gxp1→2souls/等级门 |
| 掉落被改成低概率 | **原版就是低掉率**（杂兵 15%、BOSS 100% 新手装） | **中高** | SWF prob 值 + 攻略"首关掉新手装" + 团队已确认单掷模型 |
| 早期怪血量整体被魔改 | **无证据**，三路同量级 | **中** | 对照表；差异属版本差。缺干净原版 SWF 做 diff |

**唯一的口径偏差（非魔改，但值得记）**：乌鸦经验清零门槛，SWF 写的是英雄**等级 ≥ 10**（`Monster30.as`），网络攻略写"**8 级以上**"。差 1–2 级，可能是版本差或攻略笼统。若追求原味可考虑对齐到 8 级，但影响极小。

## 四、技能激活 / 灵魂 / 技能书机制（独立重点产出，含出处）

用户点名要补的上下文。三路一致，且**在我们 SWF 里直接坐实**：

### 1. 技能靠【灵魂】逐个学习与升级（核心）
- **机制**：进入角色/技能界面 → 学习技能 → 选一个主动或被动技能 → 升级 → **消耗灵魂**。（来源：0101shop / game773 攻略）
- **SWF 实证**：`export/shop/SkillControl.as:106` 与 `:314` 明写 `"升级需要" + _loc3_ + "灵魂"`。升级消耗公式（逐字）：
  ```
  升级需要灵魂 = 150 * sl * sl * Math.sqrt(sl)   // sl = 该技能当前等级，即 150·level^2.5
  ```
  例：1→2 级 150、2→3 级 ≈848、3→4 级 ≈2338、4→5 级 4800、5→6 级 ≈8385…（随等级陡增）。
- **灵魂来源**：怪物掉落（怪的 `gxp`，掉落时 `dropAura` 用 `gxp*2`，见 `BaseMonster.as:901`）；副本（玄风洞、时空裂缝电母翻牌）等。
- **每个技能有独立等级曲线**：ZMXY `skills.json` 里每个技能的 `mpCost`/`damageFormula` 是按 `level` 展开的 9–10 段数组，对应技能等级；伤害形如 `A*e^(k*level)+…*critMult*gxpMult`。

### 2. 主动技能最多装备 5 个
- 攻略："主动技能只能选择 5 个使用"。与 SWF 键位一致（Y/L/U/I/O = 技能 1–5，见 ZMXY README 与 gameConstants）。

### 3. 【技能书】是另一条独立线（不是灵魂）
- **机制**：每个角色有**专属技能书**，用来**强化某一个特定技能**（不是通用升级）。来源：**商城购买 / 活动 / 任务**，不消耗灵魂。（来源：3dmgame / 9game / ZOL 攻略）

### 4. 升错可重置
- 用**孟婆药剂**重置技能等级返还灵魂。（来源：0101shop 攻略）

### 5. 灵魂的其它用途
- 学习升级技能（主）、**魂器装备进阶**、**神秘商店**购买道具。（来源：多篇攻略）

**一句话**：技能不是"点满即用"，而是**用灵魂逐级喂**（成本 150·level^2.5 陡增）、**主动技能限选 5**、外加**技能书**这条道具线强化单个技能、**孟婆药剂**兜底重置。灵魂 = 怪物掉的 gxp。这条链在 SWF 与网络攻略**双向印证**，高置信。
